- `schemas/catalog.json` and `crates/liter-llm/schemas/catalog.json` are generated by `liter-llm-catalog-gen` from models.dev; regenerate them, do not hand-edit.
- Regenerate with `mise run generate:catalog`; `mise run generate:catalog:check` (`--validate`) fails when the committed files are stale.
- `--dry-run` prints without writing; `--input <file>` skips the network fetch (use it in tests, see `crates/liter-llm-catalog-gen/tests/fixtures/sample_api.json`).
- `--validate` fetches models.dev live, so it is not hermetic: `catalog-verify.yml` is manual-only; `sync-catalog.yml` regenerates daily and opens a PR on drift.
- Runtime catalog refresh (overlay over the embedded catalog) is documented in `docs-site/src/content/docs/guides/catalog-refresh.md`.
